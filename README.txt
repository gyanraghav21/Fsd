TASKFLOW — READY WEBSITE

QUICK PREVIEW:
1. Extract the ZIP.
2. Open index.html in Chrome. Task creation, edit, delete, filters, search and statistics work.
3. Data is saved in this browser using localStorage.

PUBLISH ONLINE:
1. Open https://app.netlify.com/drop in your browser.
2. Sign in or create a Netlify account if asked.
3. Extract the ZIP and drag the TaskFlow_Ready_Website folder (containing index.html) into the drop area.
4. Netlify will publish it and give you a public URL.

NOTE:
This is the quick, browser-storage version for easy preview/deployment. The separate TaskFlow_Full_Stack_Project.zip contains the React + Node/Express backend project.
